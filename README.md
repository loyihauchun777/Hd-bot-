# Tungikino Telegram Bot

Bu loyiha Telegram botning boshlang‘ich ishlaydigan versiyasi.

## Muhim
Faqat o‘zingizga tegishli, litsenziyalangan yoki tarqatishga ruxsatingiz bor kontentning havolalaridan foydalaning. Botning o‘zi kontentning qonuniyligini tekshirmaydi.

## Railway
1. GitHub repository yarating va fayllarni yuklang.
2. Railway → New Project → Deploy from GitHub Repo.
3. Variables bo‘limida:
   - BOT_TOKEN = BotFather tokeningiz
   - ADMIN_ID = 8682423273
4. Deploy qiling. Railway Python start commandni aniqlay oladi; kerak bo‘lsa Start Command sifatida `python main.py` qo‘ying.

## Admin buyruqlari
- `/admin`
- `/addmovie kod | nom | sifat | havola`
- `/delmovie kod`
- `/movie kod`
- `/addchannel chat_id | nomi | havola`
- `/delchannel ID`

## Majburiy obuna
1 tadan 8 tagacha kanalni bazaga qo‘shish mumkin.
Bot majburiy obuna tekshiruvi uchun qo‘shilgan kanal/guruhda kerakli Telegram admin huquqlariga ega bo‘lishi kerak.
